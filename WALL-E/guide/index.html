WALL-E build guide

Seven parts, in the order you need them. Each part is one page. If you only have five minutes, read part 1.

The rule that comes before everything: the two track pods are already built. Nothing in this project changes them, and no new hole goes into one. Their numbers live in pod_interface.scad, checked against the newest pod revision on disk by ./pod_latest.sh + check_pod_interface.scad. If that check ever says MISMATCH, stop — every dimension downstream is wrong.

How to actually work in this repo

  1. Change the model in cad/walle_frame.scad, or the pod numbers in pod_interface.scad.
  2. Run ./render_all.sh. It points at the newest pod revision, checks the interface, runs every guard, then redraws the sheets and views. It stops at the first thing that does not agree.
  3. Run python3 build_guides.py if you edited any markdown, so these pages match.
  4. Commit. The PNGs in blueprint/ and cad/ are outputs — never hand-edit them.
